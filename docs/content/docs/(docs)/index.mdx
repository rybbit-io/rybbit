**Rybbit** is a powerful open source web and product analytics platform. Check out our [live demo](https://demo.rybbit.com/81) using a real production site.

<DocsHomeCards />

## Getting Started

Choose the option that's right for you:

- **Cloud Version:** Sign up for the [hosted version](https://app.rybbit.io/signup). Get up and running in minutes.
- **Self-Host:** Follow our [self hosting guide](/docs/self-hosting) to set up Rybbit on your own server.

And then learn how to add the [tracking script](/docs/script) to your website to start collecting data.

## Using the dashboard

- [Feature guides](/docs/feature-guides/main-tab) walk through each page of a site's dashboard, from the main dashboard to sessions, replays, errors, and [bots](/docs/feature-guides/bots).
- [Goals](/docs/goals), [funnels](/docs/funnels), and [segments](/docs/segments) turn raw traffic into conversions and saved views.
- [Annotations](/docs/annotations) pin launches, deploys, and outages to the traffic chart.
- [Rollup](/docs/rollup) shows every site in your organization on one page.
- [Custom dashboards and SQL](/docs/dashboards) let you query raw events directly (Rybbit Cloud, or a client image you build yourself).
- [Keyboard shortcuts](/docs/keyboard-shortcuts) cover the <kbd>⌘</kbd> <kbd>K</kbd> command palette and the date range hotkeys.
