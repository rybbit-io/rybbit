Rybbit works on any site that can load a script tag. Each guide below shows exactly where the tracking snippet goes on that platform and how to confirm it is working.

Don't see your platform? Paste the snippet from **Site Settings → Tracking Script** into the `<head>` of every page, or follow the [tracking script](/docs/script) reference.
