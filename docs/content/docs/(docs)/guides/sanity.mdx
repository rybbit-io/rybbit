Sanity is a headless CMS: your frontend queries content from the Content Lake and Sanity Studio is only the editing app. The tracking snippet therefore goes into the frontend that renders your site, not into Sanity.

## Troubleshooting

- **Embedded Studio pageviews**: if Sanity Studio is mounted inside your frontend (for example at `/studio` in a Next.js app), the snippet in your root layout also runs there. Add `data-skip-patterns='["/studio/**"]'` to the script tag so editor sessions are not counted as visits.
- **Hosted Studio is not tracked**: a Studio deployed to `*.sanity.studio` is a separate app without the snippet, so time spent editing never appears in Rybbit.
