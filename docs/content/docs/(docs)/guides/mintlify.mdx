### Add the snippet to Mintlify

Create a JavaScript file in your content directory, next to `docs.json` and your `.mdx` pages:

```javascript filename="rybbit.js"
(function () {
  var el = document.createElement("script");
  el.src = "https://app.rybbit.io/api/script.js?siteId=YOUR_SITE_ID";
  el.defer = true;
  document.head.appendChild(el);
})();
```

Commit and deploy. Mintlify picks the file up automatically; there is nothing to register in `docs.json`. See Mintlify's [custom scripts](https://www.mintlify.com/docs/customize/custom-scripts) page for the current rules on file placement.

To pass [script attributes](/docs/script#script-attributes) such as skip patterns, set them on the element before appending it:

```javascript filename="rybbit.js"
el.setAttribute("data-skip-patterns", JSON.stringify(["/internal/**"]));
```

<Callout type="info">
Mintlify sites are single-page apps. Rybbit records client-side navigation as pageviews, so no extra code is needed.
</Callout>

## Track custom events

Mintlify pages are MDX, so you can attach handlers inline:

```mdx
<button
  onClick={() => window.rybbit?.event("download_clicked", { file: "getting-started.pdf" })}
>
  Download guide
</button>
```
