Laravel makes it straightforward to proxy Rybbit tracking using routes and the HTTP client. This guide shows how to set up proxy endpoints in your Laravel application.

<Callout type="warn">
**Two settings make or break a first-party proxy:**

1. Enable **First-Party Proxy** in your Rybbit **Site Settings → Privacy & Security**, so the visitor IP your proxy forwards in `X-Forwarded-For` is trusted directly.
2. Forward **all** of the browser's request headers, not a hand-picked few. Rybbit's bot detection expects the headers every real browser sends (`Accept`, `Accept-Language`, `Accept-Encoding`, `Sec-Fetch-*`) — proxies that forward only `User-Agent` get their events accepted with `200 OK` but classified as bot traffic. Use `X-Forwarded-For` for the visitor IP; `X-Real-IP` does not survive Rybbit Cloud's edge.
</Callout>

## Overview

Laravel's HTTP client (built on Guzzle) provides an elegant way to proxy requests to Rybbit servers while maintaining full control over headers, caching, and error handling.

**What you'll achieve:**
- Proxy all Rybbit endpoints through your Laravel app
- Forward necessary headers for accurate tracking
- Optional caching with Laravel Cache
- Support all Rybbit features

## Prerequisites

- Laravel 8 or later
- Your Rybbit instance URL:
  - **Cloud hosted**: `https://app.rybbit.io`
  - **Self-hosted**: Your instance URL
- Your Rybbit site ID

## Implementation

<Steps>

### Configure Environment Variables

Add your Rybbit host to `.env`:

```bash
# .env
RYBBIT_HOST=https://app.rybbit.io
# For self-hosted: RYBBIT_HOST=https://analytics.yourcompany.com
```

### Create Analytics Controller

Generate a controller for handling analytics proxying:

```bash
php artisan make:controller AnalyticsProxyController
```

Then implement the proxy logic:

```php
<?php
// app/Http/Controllers/AnalyticsProxyController.php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Log;

class AnalyticsProxyController extends Controller
{
    // Headers that describe the hop to your app, not the visitor's browser.
    private const SKIP_HEADERS = [
        'host', 'content-length', 'connection', 'cookie', 'keep-alive',
        'transfer-encoding', 'upgrade', 'x-forwarded-for', 'x-forwarded-host',
        'x-forwarded-proto', 'x-forwarded-port', 'x-real-ip',
    ];

    private string $rybbitHost;

    public function __construct()
    {
        $this->rybbitHost = rtrim(config('services.rybbit.host', 'https://app.rybbit.io'), '/');
    }

    /**
     * Scripts (GET), cached for 1 hour
     */
    public function proxyScript(Request $request, string $script)
    {
        return $this->cached("rybbit_script_{$script}", 3600, "api/{$script}", $request);
    }

    /**
     * Site tracking config (GET), cached for 5 minutes
     */
    public function proxySiteConfig(Request $request, string $siteId)
    {
        return $this->cached("rybbit_config_{$siteId}", 300, "api/site/tracking-config/{$siteId}", $request);
    }

    /**
     * Every POST endpoint: track, identify, feature flags, session replay
     */
    public function proxyPost(Request $request)
    {
        // Strip the leading "analytics/" and forward to the same path under /api
        $path = 'api/' . substr($request->path(), strlen('analytics/'));

        return $this->forward('POST', $path, $request);
    }

    private function cached(string $key, int $ttl, string $path, Request $request)
    {
        $cached = Cache::get($key);

        if ($cached === null) {
            $response = $this->forward('GET', $path, $request);

            if ($response->getStatusCode() !== 200) {
                return $response;
            }

            $cached = [
                'body' => $response->getContent(),
                'type' => $response->headers->get('Content-Type'),
            ];
            Cache::put($key, $cached, $ttl);
        }

        return response($cached['body'], 200)->header('Content-Type', $cached['type']);
    }

    private function forward(string $method, string $path, Request $request)
    {
        $url = "{$this->rybbitHost}/{$path}";

        // Pass the browser's headers through; Rybbit's bot detection expects them.
        $headers = collect($request->headers->all())
            ->reject(fn ($value, $name) => in_array(strtolower($name), self::SKIP_HEADERS, true))
            ->map(fn ($values) => implode(', ', $values))
            ->all();

        // The visitor IP. $request->ip() honors your TrustProxies settings.
        $headers['X-Forwarded-For'] = $request->ip();
        // Keep an encoding the HTTP client can decode (bot detection expects gzip).
        $headers['Accept-Encoding'] = 'gzip';

        $http = Http::timeout(30)->withHeaders($headers);

        try {
            $response = $method === 'POST'
                // Forward the raw body. $request->all() would pass through
                // ConvertEmptyStringsToNull, and Rybbit rejects null fields.
                ? $http->withBody($request->getContent(), $request->header('Content-Type', 'application/json'))->post($url)
                : $http->get($url);

            return response($response->body(), $response->status())
                ->header('Content-Type', $response->header('Content-Type') ?: 'text/plain');
        } catch (\Throwable $e) {
            Log::error('Rybbit proxy error', ['url' => $url, 'error' => $e->getMessage()]);

            return response()->json(['error' => 'Analytics proxy error'], 502);
        }
    }
}
```

### Add Routes

Add routes for the analytics proxy in `routes/web.php`:

```php
<?php
// routes/web.php

use App\Http\Controllers\AnalyticsProxyController;

// Analytics proxy routes
Route::prefix('analytics')->group(function () {
    // Scripts (GET). Web vitals are bundled into script.js;
    // replay.js loads only when session replay is on.
    Route::get('/{script}', [AnalyticsProxyController::class, 'proxyScript'])
        ->where('script', '(script|replay)\.js');

    // Configuration (GET)
    Route::get('/site/tracking-config/{siteId}', [AnalyticsProxyController::class, 'proxySiteConfig']);

    // Tracking endpoints (POST)
    Route::post('/track', [AnalyticsProxyController::class, 'proxyPost']);
    Route::post('/identify', [AnalyticsProxyController::class, 'proxyPost']);
    Route::post('/site/{siteId}/feature-flags/evaluate', [AnalyticsProxyController::class, 'proxyPost']);
    Route::post('/session-replay/record/{siteId}', [AnalyticsProxyController::class, 'proxyPost']);
});
```

These routes cover every endpoint the tracking script calls. If the feature flag route is missing, `rybbit.flag()` silently returns your fallback.

Keep the proxied file named `script.js`. The script cuts its own URL at `/script.js` to find where to send events, so a renamed file (for example `/analytics/a.js`) sends every request to the wrong place.

### Exclude the Routes from CSRF Protection

Routes in `routes/web.php` run Laravel's CSRF check, which rejects the tracker's POSTs with a 419. Exclude the analytics paths.

<Tabs items={['Laravel 11+', 'Laravel 10 and earlier']}>
<Tab>

```php
<?php
// bootstrap/app.php

use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Middleware;

return Application::configure(basePath: dirname(__DIR__))
    // ...
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->validateCsrfTokens(except: [
            'analytics/*',
        ]);
    })
    // ...
    ->create();
```

</Tab>
<Tab>

```php
// app/Http/Middleware/VerifyCsrfToken.php
protected $except = [
    'analytics/*',
];
```

</Tab>
</Tabs>

## How It Works

Laravel routes intercept requests to `/analytics/*` and forward them to Rybbit:

1. Request to `/analytics/script.js` hits Laravel route
2. Controller forwards to `https://app.rybbit.io/api/script.js`
3. Response is cached (for cacheable endpoints)
4. The browser's headers are passed through, and the visitor IP goes in `X-Forwarded-For`

## Advanced Configuration

### Rate Limiting

Laravel's built-in `throttle` middleware limits requests per visitor IP. For example, 100 requests per minute:

```php
Route::prefix('analytics')->middleware('throttle:100,1')->group(function () {
    // ... routes
});
```

Session replay sends batches every few seconds while recording, so don't set the limit so low that active visitors hit it.

### Custom Cache Configuration

Use different cache drivers for analytics:

```php
private function cached(string $key, int $ttl, string $path, Request $request)
{
    // Use Redis for analytics caching
    $cache = Cache::store('redis');

    // Or use file cache
    // $cache = Cache::store('file');

    // ... rest of the method, calling $cache->get() / $cache->put()
}
```

### Don't Queue Tracking Requests

<Callout type="warn">
Forward every analytics request synchronously and return Rybbit's response. Don't hand session replay, `/track` or `/identify` requests to a queued job that answers right away:

- The tracker reads the replay endpoint's response. Rybbit uses it to tell the tracker to stop recording (when a session hits the replay size cap) or to take a fresh full snapshot. A queued proxy that always answers `queued` hides both.
- A job runs outside the request, so it no longer has the browser's headers. Batches forwarded with only an IP and user agent are classified as bot traffic.
</Callout>

### CORS Configuration

If serving from a different domain:

```php
<?php
// config/cors.php

return [
    'paths' => ['analytics/*'],
    'allowed_methods' => ['GET', 'POST'],
    'allowed_origins' => ['https://yourdomain.com'],
    'allowed_headers' => ['Content-Type', 'X-Requested-With'],
];
```

## Troubleshooting

### 404 Not Found

**Problem**: Routes return 404.

**Solution**:
1. Clear route cache: `php artisan route:clear`
2. List routes to verify: `php artisan route:list --path=analytics`
3. Check route order (more specific routes first)

### Session errors with POST requests

**Problem**: CSRF token errors on tracking endpoints.

**Solution**:
Exclude `analytics/*` from CSRF protection. See [Exclude the Routes from CSRF Protection](#exclude-the-routes-from-csrf-protection) for Laravel 11+ (`bootstrap/app.php`) and earlier versions.

### Incorrect geolocation

**Problem**: All visitors show server's location.

**Solution**:
1. Enable **First-Party Proxy** in **Site Settings → Privacy & Security**.
2. Make sure the controller sets `X-Forwarded-For` to `$request->ip()`.
3. If your app runs behind a load balancer or CDN, configure Laravel's trusted proxies so `$request->ip()` returns the visitor IP rather than the load balancer's.

### Events return 200 but don't appear

**Problem**: `/analytics/track` answers 200, but the dashboard stays empty.

**Solution**:
Check that the controller passes the browser's headers through. A proxy that sends only `User-Agent` and the IP looks like a script, and its events are classified as bot traffic. Also check that POST bodies are forwarded raw with `$request->getContent()`: re-encoding `$request->all()` turns empty strings into `null`, which Rybbit rejects with a 400.

### Cache not clearing

**Problem**: Old script cached after Rybbit update.

**Solution**:
Clear specific cache key:
```bash
php artisan cache:forget rybbit_script_script.js
```

Or clear all cache:
```bash
php artisan cache:clear
```

## Performance Optimization

### Cache Optimization

```php
// Configure cache tags for easy clearing
Cache::tags(['rybbit', 'scripts'])->remember($cacheKey, 3600, function () {
    // ... fetch script
});

// Clear all Rybbit cache
Cache::tags(['rybbit'])->flush();
```

### HTTP Client Optimization

```php
// Use connection pooling
Http::pool(fn (Pool $pool) => [
    $pool->get("{$this->rybbitHost}/api/script.js"),
    $pool->get("{$this->rybbitHost}/api/replay.js"),
]);
```
