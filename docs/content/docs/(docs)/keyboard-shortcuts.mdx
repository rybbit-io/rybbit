Rybbit has a command palette for jumping around and single-key shortcuts for the date range. Press <kbd>?</kbd> anywhere in the dashboard to see the full list.

<Callout>
  The command palette and the shortcut sheet are only available when you're signed in. Signed-out visitors to a public dashboard, anyone on a private share link, and embeds don't get them.
</Callout>

## Command palette

Press <kbd>⌘</kbd> <kbd>K</kbd> on macOS or <kbd>Ctrl</kbd> <kbd>K</kbd> on Windows and Linux. You can also click **Search** at the top of the site sidebar. The shortcut works even while you're typing in a field, and pressing it again closes the palette.

Type to search, use the arrow keys to pick a row, and press <kbd>Enter</kbd> to run it. The palette lists:

- **This site**: every page in the site sidebar you have access to (Main, Pages, Sessions, Goals, Query, and so on). Switching pages keeps your date range and filters.
- **Switch site**: the other sites in your organization. You land on the same page of the other site.
- **Goals**, **Funnels**, and **Dashboards**: the open site's saved goals, funnels, and custom dashboards.
- **Date range**: the date presets, on pages that have a date selector.
- **Navigate**: Home, Rollup, Account, and the Organization, Teams, and Billing settings if your role can open them.
- **Theme**: Light, Dark, or System.
- **Preferences**: opens the keyboard shortcut sheet.

Before you type, the palette shows up to five sites, goals, funnels, and dashboards. Typing searches all of them.

## Shortcut sheet

Press <kbd>?</kbd> to open the **Keyboard shortcuts** sheet. Press <kbd>?</kbd> or <kbd>Esc</kbd> to close it. It doesn't open while you're typing in a field.

### General

| Action | Keys |
| --- | --- |
| Open command palette | <kbd>⌘</kbd> <kbd>K</kbd> / <kbd>Ctrl</kbd> <kbd>K</kbd> |
| Show keyboard shortcuts | <kbd>?</kbd> |

### Date range

These work on any page with a date selector. They're ignored while you're typing in a field.

| Range | Key |
| --- | --- |
| Last 30 Minutes | <kbd>R</kbd> |
| Last 24 Hours | <kbd>H</kbd> |
| Today | <kbd>D</kbd> |
| Yesterday | <kbd>E</kbd> |
| Last 7 Days | <kbd>W</kbd> |
| Last 30 Days | <kbd>T</kbd> |
| This Month | <kbd>M</kbd> |
| This Year | <kbd>Y</kbd> |
| All Time | <kbd>A</kbd> |
| Custom range | <kbd>C</kbd> |

This Week has no key. The letters follow Plausible's scheme, so they'll feel familiar if you've used it.

### Session replay

| Action | Key |
| --- | --- |
| Back 10 seconds | <kbd>←</kbd> |
| Forward 10 seconds | <kbd>→</kbd> |
| Play or pause | <kbd>Space</kbd> |

### Dashboard editing

While you edit a [custom dashboard](/docs/dashboards):

| Action | Keys |
| --- | --- |
| Save changes | <kbd>⌘</kbd> <kbd>S</kbd> / <kbd>Ctrl</kbd> <kbd>S</kbd> |
| Cancel editing | <kbd>Esc</kbd> |
