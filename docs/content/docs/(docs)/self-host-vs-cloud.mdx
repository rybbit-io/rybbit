Rybbit offers two deployment options: a fully-managed [cloud version](https://rybbit.com) and a [self-hosted](/docs/self-hosting) solution. This guide will help you choose the right option for your needs.

## Quick Comparison

| **Setup Time**              | Minutes    | 30 - 120 minutes       |
| **Maintenance Required**    | None       | Regular updates |

Self-hosted instances don't send email. To add someone to an organization, an admin creates their account directly with an email and password (**Create User** in organization settings) instead of sending an invitation, and there is no "Forgot password?" link on the login page.

Custom SQL queries are still available to AI assistants on self-hosted instances through the [MCP](/docs/mcp) `run_query` tool.
