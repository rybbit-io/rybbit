Open your account settings by clicking **Account** in the settings sidebar or going to [app.rybbit.io/settings/account](https://app.rybbit.io/settings/account). Your profile, sign-in and personal API keys go with you into every organization you belong to.

![account settings](/docs/account-settings.png)

The page has five sections: **Profile**, **Preferences**, **Sign-in & security**, **Personal API keys** and **Danger zone**. The **Sign out** button sits at the top right.

## Profile

### Name

Your display name, shown to teammates in member lists.

### Email

The address you use to sign in and receive reports and invitations. To change it, click **Change email**, enter the new address and click **Send confirmation link**:

- If your current email is verified, Rybbit first emails a confirmation link to your current address, then a link to the new address. The new address takes over once you click both.
- If your current email isn't verified, Rybbit emails a link to the new address only. It takes over once you click that link.

## Preferences

### Weekly email reports <span className="text-green-500 text-sm">(Cloud)</span>

Turn on to receive a weekly traffic summary for each site you can access.

### Language

The language used for menus and labels in the dashboard.

## Sign-in & security

### Password

Click **Change password**, enter your current password and a new one, and confirm it. Passwords must be at least 8 characters.

## Personal API keys

Personal API keys act as you, with your role in each organization, and stop working if you leave that organization. For an integration that should keep working when people leave, use an [organization API key](/docs/organization-settings#organization-api-keys) instead.

### Creating an API key

1. Click **Create key**
2. Enter a **Key name** so you can tell your keys apart
3. Optionally turn on **Restrict permissions** to limit the key to specific resources. Leave it off for a full-access key that can do anything you can.
4. Click **Create key**
5. Copy and store the key right away

<Callout type="warn">
  On Rybbit Cloud, API keys are available on Standard and Pro plans. On other plans you'll see an **Upgrade your plan** button instead of **Create key**.
</Callout>

<Callout type="warn">
  You see the key once, right after you create it. You can't view it again.
</Callout>

### Managing API keys

Your keys are listed in a table with these columns:
- **Name** - The name you gave the key
- **Key** - A preview of the key (first few characters)
- **Permissions** - **Full access**, or the access and resources a restricted key has
- **Created** - When the key was created
- **Last used** - When the key last made a request

Delete a key you no longer need. Deleting a key revokes access immediately for anything using it.

### Using API keys

Send your API key with requests to Rybbit's API. See [API getting started](/docs/api/getting-started) for authentication and available endpoints.

## Danger zone

### Delete account

Deleting your account removes your profile, your sign-in and your personal API keys, and removes you from every organization. Organizations, their sites and their analytics data are not deleted.

To confirm, click **Delete account**, then press and hold **Hold to delete account**.

<Callout type="warn">
  This cannot be undone. If you're the only owner of an organization with an active subscription, you can't delete your account until you cancel that subscription in [Billing](/docs/billing-settings) or make someone else an owner.
</Callout>
