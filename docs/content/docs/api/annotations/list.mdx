```
GET /api/sites/:site/annotations
```

Returns the annotations pinned to the site's traffic chart, ordered by date. Organization-wide annotations (those with a `null` `siteId`) are included for every site in the organization.

Anonymous viewers of a public dashboard or a private link only receive annotations with `isPublic: true`.

### Path Parameters

<TypeTable
  type={{
    site: {
      description: 'Site ID or site identifier',
      type: 'string | number',
      required: true,
    },
  }}
/>

### Query Parameters

<TypeTable
  type={{
    start_date: {
      description: 'Only annotations that end on or after the start of this day (YYYY-MM-DD). May be sent without end_date.',
      type: 'string',
      required: false,
    },
    end_date: {
      description: 'Only annotations that start before the end of this day (YYYY-MM-DD). May be sent without start_date; must not precede start_date.',
      type: 'string',
      required: false,
    },
    time_zone: {
      description: 'IANA timezone the day bounds are read in',
      type: 'string',
      default: 'UTC',
      required: false,
    },
  }}
/>

### Response

An array of annotation objects.

<TypeTable
  type={{
    annotationId: { description: 'Unique annotation ID', type: 'number' },
    siteId: { description: 'Site the annotation belongs to, or null for organization-wide annotations', type: 'number | null' },
    organizationId: { description: 'Owning organization', type: 'string' },
    userId: { description: 'Creator user ID', type: 'string | null' },
    userName: { description: 'Creator display name', type: 'string | null' },
    title: { description: 'Short title shown on the chart', type: 'string' },
    description: { description: 'Longer note', type: 'string | null' },
    date: { description: 'ISO 8601 timestamp the annotation is pinned to', type: 'string' },
    endDate: { description: 'ISO 8601 end timestamp for range annotations', type: 'string | null' },
    color: { description: 'Marker color', type: 'string | null', typeDescription: '"amber" | "rose" | "sky" | "violet" | "lime" | null' },
    icon: { description: 'Emoji shown in the marker', type: 'string | null' },
    isPublic: { description: 'Whether public dashboards and private links show it', type: 'boolean' },
    createdAt: { description: 'Creation timestamp', type: 'string' },
    updatedAt: { description: 'Last update timestamp', type: 'string' },
  }}
/>
