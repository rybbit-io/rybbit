```
DELETE /api/sites/:site/annotations/:annotationId
```

Deletes an annotation. Admins and owners can delete any annotation on their sites; members can delete only the annotations they created.

### Path Parameters

<TypeTable
  type={{
    site: { description: 'Site ID or site identifier', type: 'string | number', required: true },
    annotationId: { description: 'Annotation ID', type: 'number', required: true },
  }}
/>

</div>
<div>

### Example

<Tabs items={['cURL', 'Response']}>
<Tab value="cURL">

```bash
curl -X DELETE "https://app.rybbit.io/api/sites/123/annotations/43" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

</Tab>
<Tab value="Response">

```json
{ "success": true }
```
