```
GET /api/sites/:site/bots/ai-summary
```

Returns one row per AI operator: how much of your site it read, and how many visits it sent back.

The two numbers come from different places. Reads are bot events whose user agent names the operator; visits back are sessions in your normal analytics that arrived from that company's product (the `AI` acquisition channel). Neither is very interesting alone — "OpenAI read 4,120 pages and sent 12 visits" is the sentence this endpoint exists to produce.

Operators that only read, and operators that only referred, both appear; the missing side reads `0`.

### Path Parameters

<TypeTable
  type={{
    site: {
      description: 'Site ID or site identifier',
      type: 'string | number',
      required: true,
    },
  }}
/>

### Query Parameters

Accepts all [Common Parameters](/docs/api/getting-started#common-parameters) (time and filters).

Filters apply to both halves, using the bot filter subset described in [Get Bots by Dimension](/docs/api/bots/by-dimension).

### Response

<TypeTable
  type={{
    data: {
      description: 'Array of operator rows, ordered by reads descending',
      type: 'AiSummaryRow[]',
    },
  }}
/>

#### AiSummaryRow Object

<TypeTable
  type={{
    operator: {
      description: 'Who runs the bot, e.g. "OpenAI"',
      type: 'string',
    },
    crawls: {
      description: 'Total AI requests from this operator',
      type: 'number',
    },
    training_crawls: {
      description: 'Requests with purpose ai_training',
      type: 'number',
    },
    search_crawls: {
      description: 'Requests with purpose ai_search',
      type: 'number',
    },
    agent_requests: {
      description: 'Requests with purpose ai_agent',
      type: 'number',
    },
    referrals: {
      description: 'Sessions that arrived from this operator\'s product',
      type: 'number',
    },
    crawls_per_referral: {
      description: 'Reads per visit sent back. 0 when the operator sent nobody back — there is no rate to report.',
      type: 'number',
    },
  }}
/>

<Callout>
Only bots that execute JavaScript reach Rybbit. Crawlers that fetch HTML and run nothing — which includes most training crawlers — are absent unless your server reports them. See [Bot detection](/docs/bot-detection#reporting-crawlers-that-never-run-javascript).
</Callout>
