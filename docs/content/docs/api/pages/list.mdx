```
GET /api/sites/:site/pages
```

Returns the Pages report: one row per path (or per section, the first path segment), with entry, exit, time-on-page and bounce figures computed from the same pass over the site's pageviews. A pageview with no earlier pageview in its session is an entry, one with no later pageview is an exit, and one with neither is a bounce.

**Permissions:** any role on the site (`viewer` and above). API keys need the `analytics:read` scope. Public sites and [private links](/docs/api/sites/get-private-link) can read it without a key.

### Path Parameters

### Query Parameters

Accepts all [Common Parameters](/docs/api/getting-started#common-parameters) (time and filters). Time parameters are optional; omit them for all-time data.

<TypeTable
  type={{
    group: {
      description: "Return one row per path, or one row per section",
      type: "string",
      typeDescription: "\"page\" | \"section\"",
      default: "page",
      required: false,
    },
    section: {
      description: "Only paths in this section (e.g. \"/docs\"). Page rows only. Max 2048 characters",
      type: "string",
      required: false,
    },
    mode: {
      description: "`entry` keeps only rows with entries, `exit` only rows with exits",
      type: "string",
      typeDescription: "\"all\" | \"entry\" | \"exit\"",
      default: "all",
      required: false,
    },
    sort: {
      description: "Sort column",
      type: "string",
      typeDescription: "\"pageviews\" | \"sessions\" | \"entries\" | \"exits\" | \"time_on_page\" | \"bounce_rate\"",
      default: "pageviews",
      required: false,
    },
    order: {
      description: "Sort direction. Nulls sort last either way",
      type: "string",
      typeDescription: "\"asc\" | \"desc\"",
      default: "desc",
      required: false,
    },
    search: {
      description: "Case-insensitive substring matched against the path or title. Page rows only. Max 200 characters",
      type: "string",
      required: false,
    },
    limit: {
      description: "Rows per page",
      type: "number",
      typeDescription: "1-100",
      default: 25,
      required: false,
    },
    page: {
      description: "Page number (1-indexed)",
      type: "number",
      typeDescription: "1-10000",
      default: 1,
      required: false,
    },
  }}
/>

`section` and `search` can't be combined with `group=section`; the request is rejected with a `400`.

#### PageRow Object

<TypeTable
  type={{
    kind: {
      description: "Row type. With `group=section`, a section that contains only one page is returned as that page",
      type: "string",
      typeDescription: "\"page\" | \"section\"",
    },
    key: {
      description: "The path for a page row, the section for a section row",
      type: "string",
    },
    title: {
      description: "The page's most recent non-empty title; empty for sections and untitled pages",
      type: "string",
    },
    section: {
      description: "The first path segment the row belongs to (e.g. \"/docs\" for \"/docs/api\"); \"/\" is its own section",
      type: "string",
    },
    pages: {
      description: "Number of distinct paths in the row (1 for a page row)",
      type: "number",
    },
    pageviews: {
      description: "Total pageviews",
      type: "number",
    },
    sessions: {
      description: "Unique sessions that viewed the page",
      type: "number",
    },
    entries: {
      description: "Pageviews that were the first of their session",
      type: "number",
    },
    exits: {
      description: "Pageviews that were the last of their session",
      type: "number",
    },
    bounced_entries: {
      description: "Entries that were the only pageview of their session",
      type: "number",
    },
    time_on_page_seconds: {
      description: "Average seconds to the next pageview, capped at 1800 per view. Exit views have no next view and are left out of the average",
      type: "number | null",
    },
    bounce_rate: {
      description: "bounced_entries as a percentage of entries; null when the row has no entries",
      type: "number | null",
      typeDescription: "Range: 0-100",
    },
  }}
/>

`totalCount` is the number of rows across all pages of results.
