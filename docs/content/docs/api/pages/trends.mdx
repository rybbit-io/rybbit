```
GET /api/sites/:site/pages/trends
```

Returns a pageview time series for each requested path and section. A pageview counts toward its path and toward its section when both are requested.

**Permissions:** any role on the site (`viewer` and above). API keys need the `analytics:read` scope. Public sites and [private links](/docs/api/sites/get-private-link) can read it without a key.

### Path Parameters

<TypeTable
  type={{
    site: {
      description: "Site ID or site identifier",
      type: "string | number",
      required: true,
    },
  }}
/>

### Query Parameters

Accepts all [Common Parameters](/docs/api/getting-started#common-parameters) (time and filters). Time parameters are optional; omit them for all-time data.

<TypeTable
  type={{
    paths: {
      description: "JSON-encoded array of paths, e.g. [\"/pricing\",\"/docs/api\"]",
      type: "string",
      required: false,
    },
    sections: {
      description: "JSON-encoded array of sections (first path segment), e.g. [\"/blog\"]",
      type: "string",
      required: false,
    },
    bucket: {
      description: "Time bucket size",
      type: "TimeBucket",
      typeDescription: "\"minute\" | \"five_minutes\" | \"ten_minutes\" | \"fifteen_minutes\" | \"hour\" | \"day\" | \"week\" | \"month\" | \"year\"",
      default: "day",
      required: false,
    },
  }}
/>

Pass at least one path or section, and at most 50 in total (each up to 2048 characters).

### Response

<TypeTable
  type={{
    data: {
      description: "One entry per requested path or section that had pageviews in the period. Keys with no views are omitted",
      type: "PageTrend[]",
    },
  }}
/>

#### PageTrend Object

<TypeTable
  type={{
    kind: {
      description: "Whether `key` is a path or a section",
      type: "string",
      typeDescription: "\"page\" | \"section\"",
    },
    key: {
      description: "The path or section",
      type: "string",
    },
    pageviews: {
      description: "Total pageviews in the period (the sum of `series`)",
      type: "number",
    },
    series: {
      description: "Pageviews per bucket. `time` is the bucket start as `YYYY-MM-DD HH:MM:SS`, wall-clock in `time_zone`. Empty buckets are filled with 0 when the request has a time range; all-time requests are not filled",
      type: "{ time: string, pageviews: number }[]",
    },
  }}
/>
