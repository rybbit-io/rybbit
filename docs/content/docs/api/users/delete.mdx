```
DELETE /api/sites/:site/users/:userId
```

Permanently deletes a user's data on this site, for erasure requests. `userId` can be an identified user ID or an anonymous device ID. The following is removed:

- Events identified as this user
- Anonymous (never identified) events from this ID and from every device linked to it with `identify()`
- Session replay events and recordings for the same rows. On Rybbit Cloud, deleting the stored recording files is best effort: a failure there is logged, not reported, so the response can be `success: true` while some recording payloads remain
- The user's profile (traits) and device links

Events a linked device recorded while identified as a *different* user are kept, so a shared device doesn't erase someone else's history. This action cannot be undone.

**Permissions:** the `editor` role or above on the site. API keys need the `users:write` scope.
