```
GET /api/sites/:site/users
```

Returns a paginated list of users with their analytics data. Supports filtering by identified users only.

### Path Parameters

<TypeTable
  type={{
    site: {
      description: 'Site ID or site identifier',
      type: 'string | number',
      required: true,
    },
  }}
/>

### Query Parameters

Accepts all [Common Parameters](/docs/api/getting-started#common-parameters) plus the following. A malformed `page`, `page_size`, `min_sessions`, or flag value returns `400`.

<TypeTable
  type={{
    page: {
      description: 'Page number (1-indexed)',
      type: 'number',
      default: 1,
    },
    page_size: {
      description: 'Number of results per page, capped at 1000',
      type: 'number',
      default: 100,
    },
    sort_by: {
      description: 'Field to sort by. Unknown values fall back to last_seen.',
      type: 'string',
      typeDescription: '"first_seen" | "last_seen" | "pageviews" | "sessions" | "events"',
      default: 'last_seen',
    },
    sort_order: {
      description: 'Sort direction',
      type: 'string',
      typeDescription: '"asc" | "desc"',
      default: 'desc',
    },
    identified_only: {
      description: 'Only return users with a custom identified_user_id',
      type: 'string',
      typeDescription: '"true" | "false"',
      default: 'false',
    },
    new_only: {
      description: 'Only users not seen in the 90 days before the requested period. For an all-time request every user counts as new.',
      type: 'string',
      typeDescription: '"true" | "false"',
      default: 'false',
    },
    min_sessions: {
      description: 'Only users with at least this many sessions in the period',
      type: 'number',
      typeDescription: '1 to 1,000,000',
      required: false,
    },
    search: {
      description: 'Case-insensitive substring search, at most 200 characters. Searches the field named by search_field.',
      type: 'string',
      required: false,
    },
    search_field: {
      description: 'What search matches. user_id matches the listed ID (identified ID, or device ID for anonymous users). username, name, and email match profile traits, so they only find identified users; at most 10,000 matching profiles are used (see searchLimited).',
      type: 'string',
      typeDescription: '"username" | "name" | "email" | "user_id"',
      default: 'username',
    },
    trait_key: {
      description: 'Limit to one group of a trait breakdown: users whose trait has this key. Needs trait_value or trait_missing=true, otherwise 400.',
      type: 'string',
      required: false,
    },
    trait_value: {
      description: 'With trait_key: only users whose trait equals this value',
      type: 'string',
      required: false,
    },
    trait_missing: {
      description: 'With trait_key: only users with no value for that trait (anonymous users included)',
      type: 'string',
      typeDescription: '"true" | "false"',
      default: 'false',
    },
  }}
/>

Filters qualify sessions; each user's totals then count every event in their matching sessions.

      required: false,
    },
  }}
