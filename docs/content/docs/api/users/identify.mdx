```
POST /api/sites/:site/users/identify
```

Links an anonymous visitor (the device fingerprint shown as `user_id` in sessions and events) to an identified user ID, the same link the tracking script's `identify()` call makes. Past events from that device are attributed to the user in the background; expect them to update within a few minutes.

This is the management endpoint. To identify a visitor as part of tracking (from a browser or server sending events), use [Sending Events](/docs/api/sending-events) or the script's [`identify()`](/docs/identify-users).

**Permissions:** the `member` role or above on the site. API keys need the `users:write` scope.

### Path Parameters

<TypeTable
  type={{
    site: {
      description: "Site ID or site identifier",
      type: "string | number",
      required: true,
    },
  }}
/>

### Request Body

<TypeTable
  type={{
    anonymous_id: {
      description: "The anonymous device ID to link",
      type: "string",
      typeDescription: "1-255 characters",
      required: true,
    },
    user_id: {
      description: "Your user ID. Must differ from anonymous_id",
      type: "string",
      typeDescription: "1-255 characters",
      required: true,
    },
    traits: {
      description: "Traits to merge into the user's existing traits. Keys with a null value are dropped. Without traits, an empty profile is created if none exists",
      type: "object",
      typeDescription: "Max 2 KB as JSON",
      required: false,
    },
  }}
/>

### Response

<TypeTable
  type={{
    success: {
      description: "Whether the user was identified",
      type: "boolean",
    },
  }}
/>

### Error Responses

Errors use the standard body `{ error, code, message, resolution }`.

<TypeTable
  type={{
    "400": {
      description: "Invalid payload (missing or oversized fields, traits over 2 KB), or user_id equal to anonymous_id",
      type: "object",
    },
    "403": {
      description: "Missing role on the site or the users:write scope",
      type: "object",
    },
    "500": {
      description: "Failed to identify user",
      type: "object",
    },
  }}
/>
