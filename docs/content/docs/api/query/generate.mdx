```
POST /api/organizations/:organizationId/analytics/query/generate
```

Uses an AI model to write a `scoped_events` query from a plain-language prompt. The generated SQL is checked against the same rules as [Run SQL Query](/docs/api/query/run) and returned; nothing is executed. Pass `currentQuery` and `history` to refine an earlier query.

**Permissions:** the `viewer` role or above in the organization. API keys need the `sql:read` scope.

**Rate limit:** 20 requests per minute per user (per organization for organization API keys). Self-hosted instances need an OpenRouter API key configured.

### Path Parameters

### Request Body

<TypeTable
  type={{
    prompt: {
      description: "What you want to know",
      type: "string",
      typeDescription: "1-4,000 characters",
      required: true,
    },
    currentSiteId: {
      description: "A site to focus on; \"this site\" in the prompt refers to it. Must be a site you can access",
      type: "number",
      required: false,
    },
    currentQuery: {
      description: "The query to revise for a follow-up request",
      type: "string",
      typeDescription: "Up to 20,000 characters",
      required: false,
    },
    history: {
      description: "Earlier turns of the conversation, oldest first. Only the last 10 are used",
      type: "{ role: \"user\" | \"assistant\", content: string }[]",
      typeDescription: "Max 12 items",
      default: "[]",
      required: false,
    },
  }}
/>

<TypeTable
