```
POST /api/organizations/:organizationId/analytics/query
```

Runs one read-only ClickHouse `SELECT` against `scoped_events`: the raw events of every site in the organization that the caller can access, or of a single site when `siteId` is given. Results are capped at 1,000 rows and 60 seconds of execution.

**Permissions:** the `viewer` role or above in the organization. API keys need the `sql:read` scope. Members with restricted site access only see their sites; organization API keys see every site in the organization.

**Rate limit:** 60 requests per minute per user (per organization for organization API keys), on top of the [standard API limits](/docs/api/getting-started#rate-limits-cloud-only).

### Query Rules

- Read from `scoped_events` only, or from CTEs you define over it. `events`, `system.*`, `information_schema.*` and other tables are rejected, and `scoped_events` can't be redefined.
- One statement, starting with `SELECT` or `WITH`.
- These keywords are rejected anywhere outside string literals: `ALTER`, `ATTACH`, `BACKUP`, `CREATE`, `DELETE`, `DESCRIBE`, `DETACH`, `DROP`, `EXCHANGE`, `EXPLAIN`, `FORMAT`, `GRANT`, `INFILE`, `INSERT`, `INTO`, `KILL`, `OPTIMIZE`, `OUTFILE`, `RENAME`, `RESTORE`, `REVOKE`, `SET`, `SETTINGS`, `SHOW`, `SYSTEM`, `TRUNCATE`, `USE`, `WATCH`.
- Table functions and functions that reach outside the events (for example `url()`, `s3()`, `file()`, `remote()`, `numbers()`, `dictGet()`, `sleep()`) are rejected.
- Double-quoted or backtick identifiers, `#` and `//` comments, nested `/* */` comments, `$$` strings, and non-ASCII characters outside string literals are rejected. Use single quotes for strings.
- Your query is wrapped as `SELECT * FROM (your query) LIMIT 1000`.

#### scoped_events Columns

| Column | Type | Description |
|--------|------|-------------|
| `site_id` | `UInt16` | Rybbit site ID |
| `timestamp` | `DateTime` | Event time (UTC) |
| `timestamp_ms` | `DateTime64(3)` | Event time with milliseconds, for ordering |
| `session_id` | `String` | Session ID |
| `user_id` | `String` | Anonymous device ID |
| `identified_user_id` | `String` | ID set via identify(); empty when not identified |
| `hostname` | `String` | Page hostname, e.g. www.example.com |
| `pathname` | `String` | URL path, e.g. /pricing |
| `querystring` | `String` | Raw query string, usually with the leading ? |
| `url_parameters` | `Map(String, String)` | Parsed query parameters, e.g. url_parameters['utm_source'] |
| `page_title` | `String` | document.title; may be empty |
| `referrer` | `String` | External referrer URL; empty for direct traffic |
| `channel` | `String` | Acquisition channel, e.g. Direct, Organic Search, Referral |
| `browser, browser_version` | `LowCardinality(String)` | Browser and major version |
| `operating_system, operating_system_version` | `LowCardinality(String)` | OS and version |
| `language` | `LowCardinality(String)` | Browser language, e.g. en-US |
| `country` | `LowCardinality(FixedString(2))` | ISO 3166-1 alpha-2 code |
| `region` | `LowCardinality(String)` | Region code, e.g. US-CA |
| `city` | `String` | City name |
| `lat, lon` | `Float64` | Coordinates; 0 when unknown |
| `screen_width, screen_height` | `UInt16` | Screen size in pixels; 0 when unavailable |
| `device_type` | `LowCardinality(String)` | Desktop, Mobile, Tablet, TV, Console or Embedded |
| `type` | `LowCardinality(String)` | pageview, custom_event, performance, outbound, error, button_click, copy, form_submit or input_change |
| `event_name` | `String` | Custom event name, error name, or web-vitals |
| `props` | `JSON` | Event properties; read with JSONExtractString(toString(props), 'key') |
| `lcp, cls, inp, fcp, ttfb` | `Nullable(Float64)` | Web vitals; set only on performance events |
| `ip` | `Nullable(String)` | Visitor IP when IP tracking is on for the site; otherwise null |
| `timezone` | `LowCardinality(String)` | Visitor timezone from geolocation |
| `tag` | `LowCardinality(String)` | Optional script tag; empty when unset |
| `import_id` | `Nullable(UUID)` | Import job ID for imported rows; null for tracked events |
| `feature_flags` | `Map(String, String)` | Feature flag values recorded with the event |
| `asn` | `Nullable(UInt32)` | Autonomous system number of the visitor's IP |
| `asn_org` | `LowCardinality(String)` | Organization that owns the ASN; empty when unknown |
| `is_datacenter_asn` | `UInt8` | 1 when the ASN belongs to a datacenter or hosting provider |
