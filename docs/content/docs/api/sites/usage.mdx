```
GET /api/sites/:site/usage
```

Returns the number of billable events the site and its whole organization have recorded since the start of the current calendar month, the organization's monthly event limit, and a month-end projection at the current rate.

Billable events are `pageview`, `custom_event`, `performance`, `outbound`, `button_click`, `copy`, `form_submit` and `input_change`. Errors are not counted.

**Permissions:** the `viewer` role or above on the site. API keys need the `sites:read` scope.

### Path Parameters

<TypeTable
  type={{
    site: {

      required: true,
    },
  }}
/>

### Response

<TypeTable
  type={{

      description: "First day of the current calendar month",

      type: "number",

    daysElapsed: {
      description: "Days since periodStart, fractional",
      type: "number",
    },

      description: "Billable events for this site this month",

    },
    orgEventsThisMonth: {

    },
    orgEventLimit: {
      description: "The organization's monthly event limit. Always null on self-hosted instances",
      type: "number | null",
    },
    projectedSiteEvents: {
      description: "Month-end projection for the site; null during the first day of the month",
      type: "number | null",
    },
    projectedOrgEvents: {
      description: "Month-end projection for the organization; null during the first day of the month",
      type: "number | null",
    },
  }}
