```
PUT /api/sites/:site/move
```

Moves a site, with all its data, into another organization. You must administer both organizations. To hand a site to someone outside your organizations, use [Create Site Transfer](/docs/api/sites/create-transfer).

Moving a site also:

- removes per-member and per-team access grants for the site (the new organization's members reach it through their own roles)
- moves the site's own segments, annotations and import history with it (organization-wide ones stay)
- cancels any pending site transfer
- disconnects Google Search Console

**Permissions:** the `admin` role or above in the site's organization. API keys need the `sites:write` scope. You also need the `admin` or `owner` role in the target organization. The move is checked against your own memberships, so organization API keys are rejected with `401`; use a personal key or a session.

### Path Parameters

<TypeTable
  type={{
    site: {
      description: "Site ID or site identifier",

      required: true,
    },
  }}
/>

### Request Body

<TypeTable
  type={{
    organizationId: {
      description: "ID of the organization to move the site into",
      type: "string",
      required: true,
    },
  }}
/>

### Response

<TypeTable
  type={{
    success: {
      description: "Whether the site was moved",
      type: "boolean",
    },
    organizationId: {
      description: "The site's new organization",
      type: "string",
    },
  }}
/>

### Error Responses

Errors use the standard body `{ error, code, message, resolution }`.

<TypeTable
  type={{
    "400": {
      description: "Invalid body, or the site is already in that organization",
      type: "object",
    },
    "401": {
      description: "No user behind the credential (organization API key)",
      type: "object",
    },
    "403": {
      description: "Not an admin or owner of the site's organization or the target organization, or the target organization is at its plan's site limit",
      type: "object",
    },
    "404": {
      description: "Site or target organization not found",
      type: "object",
    },
    "409": {
      description: "The site moved while the request was in flight",
      type: "object",
    },
  }}
/>
