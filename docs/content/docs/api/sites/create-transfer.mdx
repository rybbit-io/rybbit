```
POST /api/sites/:site/transfer
```

Emails the recipient a link that lets them move the site into one of their own organizations. Nothing moves until they [accept](/docs/api/sites/accept-transfer). A site has at most one pending transfer: creating a new one cancels the previous link. The link expires after 7 days.

The link is also returned in the response, so you can pass it on yourself if the email doesn't arrive.

**Permissions:** the `admin` role or above in the site's organization. API keys need the `sites:write` scope. A transfer must be started by a person, so organization API keys are rejected with `401`.

### Path Parameters

<TypeTable
  type={{
    site: {
      description: "Site ID or site identifier",
      type: "string | number",
      required: true,
    },
  }}
/>

### Request Body

<TypeTable
  type={{
    email: {
      description: "Recipient's email address. They must accept while signed in with this address",
      type: "string",
      required: true,
    },
  }}
/>

### Response

Returns `201` with the pending transfer.

<TypeTable
  type={{
    id: {
      description: "Transfer ID (the secret in the link)",
      type: "string",
    },
    recipientEmail: {
      description: "Recipient's email address, lowercased",
      type: "string",
    },
    createdAt: {
      description: "When the transfer was created",
      type: "string",
      typeDescription: "ISO 8601 UTC, e.g. 2026-10-31T14:22:05.000Z",
    },
    expiresAt: {
      description: "When the link stops working, 7 days after creation",
      type: "string",
      typeDescription: "ISO 8601 UTC",
    },
    url: {
      description: "Link the recipient opens to accept",
      type: "string",
    },
  }}
/>

### Error Responses

Errors use the standard body `{ error, code, message, resolution }`.

<TypeTable
  type={{
    "400": {
      description: "Missing or invalid email",
      type: "object",
    },
    "401": {
      description: "No user behind the credential (organization API key)",
      type: "object",
    },
    "403": {
      description: "Not an admin or owner of the site's organization, or missing the sites:write scope",
      type: "object",
    },
    "404": {
      description: "Site not found",
      type: "object",
    },
    "409": {
      description: "The site moved while the request was in flight",
      type: "object",
    },
  }}
/>
