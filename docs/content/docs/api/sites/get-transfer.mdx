```
GET /api/sites/:site/transfer
```

Returns the site's pending transfer. Expired transfers are returned as `null`.

**Permissions:** the `admin` role or above in the site's organization. API keys need the `sites:write` scope.

### Path Parameters

<TypeTable
  type={{
    site: {
      description: "Site ID or site identifier",
      type: "string | number",
      required: true,
    },
  }}
/>

### Response

<TypeTable
  type={{
    transfer: {
      description: "The pending transfer, or null",
      type: "SiteTransfer | null",
    },
  }}
/>

#### SiteTransfer Object

<TypeTable
  type={{
    id: {
      description: "Transfer ID (the secret in the link)",
      type: "string",
    },
    recipientEmail: {
      description: "Recipient's email address, lowercased",
      type: "string",
    },
    createdAt: {
      description: "When the transfer was created",
      type: "string",
      typeDescription: "ISO 8601 UTC, e.g. 2026-10-31T14:22:05.000Z",
    },
    expiresAt: {
      description: "When the link stops working, 7 days after creation",
      type: "string",
      typeDescription: "ISO 8601 UTC",
    },
    url: {
      description: "Link the recipient opens to accept",
      type: "string",
    },
  }}
/>
