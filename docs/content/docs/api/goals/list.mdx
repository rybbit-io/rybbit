```
GET /api/sites/:site/goals
```

Returns a paginated list of goals with their conversion metrics.

### Path Parameters

<TypeTable
  type={{
    site: {
      description: 'Site ID or site identifier',
      type: 'string | number',
      required: true,
    },
  }}
/>

### Query Parameters

Accepts all [Common Parameters](/docs/api/getting-started#common-parameters) plus the following:

<TypeTable
  type={{
    page: {
      description: 'Page number (1-indexed)',
      type: 'number',
      default: 1,
    },
    page_size: {
      description: 'Number of results per page, 1-100. Out-of-range values return 400.',
      type: 'number',
      default: 10,
    },
    sort: {
      description: 'Field to sort by',
      type: 'string',
      typeDescription: '"goalId" | "name" | "goalType" | "createdAt" (other values fall back to createdAt)',
      default: 'createdAt',
    },
    order: {
      description: 'Sort direction',
      type: 'string',
      typeDescription: '"asc" | "desc"',
      default: 'desc',
    },
  }}
/>
