```
GET /api/sites/:site/sessions/:sessionId
```

Returns detailed information about a specific session including all events and pageviews.

### Path Parameters

<TypeTable
  type={{
    sessionId: {
      description: 'Session ID',
      type: 'string',
      required: true,
    },
    site: {
      description: 'Site ID or site identifier',
      type: 'string | number',
      required: true,
    },
  }}
/>

### Query Parameters

<TypeTable
  type={{
    limit: {
      description: 'Number of events to return',
      type: 'number',
      default: 100,
    },
    offset: {
      description: 'Number of events to skip',
      type: 'number',
      default: 0,
    },
    minutes: {
      description: 'Only use events from the last N minutes. Applies to the session summary, the events, and the total. 0 or a non-numeric value is ignored, and the whole session is returned.',
      type: 'number',
      required: false,
    },
  }}
/>

Returns `404` when the session has no events (or none in the last `minutes`).

### Response

  }}
