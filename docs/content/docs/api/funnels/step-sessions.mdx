```
POST /api/sites/:site/funnels/:stepNumber/sessions
```

Returns sessions that either reached or dropped off at a specific funnel step. Useful for analyzing user behavior at each stage.

### Path Parameters

<TypeTable
  type={{
    stepNumber: {
      description: 'Step number (1-indexed)',
      type: 'string | number',
      required: true,
    },
    site: {
      description: 'Site ID or site identifier',
      type: 'string | number',
      required: true,
    },
  }}
/>

### Query Parameters

Accepts all [Common Parameters](/docs/api/getting-started#common-parameters) plus the following:

<TypeTable
  type={{
    mode: {
      description: 'reached: sessions that completed this step. dropped: sessions that completed this step but not the next one (empty for the last step).',
      type: 'string',
      typeDescription: '"reached" | "dropped"',
      required: true,
    },
    page: {
      description: 'Page number (1-indexed)',
      type: 'number',
      default: 1,
    },
    limit: {
      description: 'Number of results per page',
      type: 'number',
      default: 25,
    },
    replays_only: {
      description: 'Only return sessions that have a session replay',
      type: 'string',
      typeDescription: '"true" | "false"',
      default: 'false',
    },
  }}
/>

### Request Body

<TypeTable
  type={{
    steps: {
      description: 'Array of funnel steps (minimum 2), using the FunnelStep object from Analyze Funnel',
      type: 'FunnelStep[]',
      required: true,
    },
  }}
/>

### Response

<TypeTable
  type={{
    data: {
      description: 'Array of session objects',
      type: 'Session[]',
    },
  }}
/>

#### Session Object

Session fields other than `traits` (the identified user's current profile) are computed from the events inside the requested time range. Sessions are ordered by `session_end`, newest first.
