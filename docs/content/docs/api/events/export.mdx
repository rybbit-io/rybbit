```
GET /api/sites/:site/export/events
```

Streams every event in a date range as a file, one row per event, oldest first. Covers pageviews, custom events, outbound clicks, errors, web vitals and autocaptured interactions. IP addresses are never included.

Needs a role on the site (any role, including viewer) or an API key with the `events:read` scope. Public-site and private-link visitors cannot call it. The same export is available in the dashboard under **Site Settings → Export**.

**Limits:** one request returns at most 2,000,000 events. Larger ranges get `413` before any data is sent, so fetch long histories month by month. Rate limit: 10 requests per minute per user (per organization for organization API keys), on top of the [standard API limits](/docs/api/getting-started#rate-limits-cloud-only).

### Query Parameters

Accepts all [Common Parameters](/docs/api/getting-started#common-parameters) (time and filters). With no time parameters, exports all time.

### Response

The response body is the file itself, not JSON: `text/csv` with a header row, or `application/x-ndjson`. `Content-Disposition` names the file, and `X-Export-Rows` gives the number of events. Stream it to disk rather than buffering it.

Errors come back as JSON: `400` for malformed time parameters, filters or `format`; `403` for a site that doesn't exist or that you can't access; `413` when the range holds more than 2,000,000 events (the body includes `rows` and `maxRows`); `429` when rate limited.

### Counting first

`GET /api/sites/:site/export/events/count` takes the same parameters and returns `{ "data": { "rows": 48210, "maxRows": 2000000 } }`, so a script can check a range before downloading it.

```javascript title="Request"
import { createWriteStream } from 'node:fs';
import { Readable } from 'node:stream';
import { pipeline } from 'node:stream/promises';

const response = await fetch(
  'https://app.rybbit.io/api/sites/123/export/events?start_date=2026-01-01&end_date=2026-01-31&time_zone=UTC&format=ndjson',
  { headers: { Authorization: 'Bearer your_api_key_here' } }
);
if (!response.ok) throw new Error((await response.json()).error);

await pipeline(Readable.fromWeb(response.body), createWriteStream('events-2026-01.ndjson'));
```

  <Tab value="Python">
```python title="Request"
import requests

with requests.get(
    'https://app.rybbit.io/api/sites/123/export/events',
    params={
        'start_date': '2026-01-01',
        'end_date': '2026-01-31',
        'time_zone': 'UTC',
        'format': 'csv',
    },
    headers={'Authorization': 'Bearer your_api_key_here'},
    stream=True,
) as response:
    response.raise_for_status()
    with open('events-2026-01.csv', 'wb') as f:
        for chunk in response.iter_content(chunk_size=1 << 20):
            f.write(chunk)
```
