```
POST /api/organizations/:organizationId/users
```

Creates a new Rybbit account with an email and password and adds it to the organization with the given role, without sending an invitation. To add someone who already has an account, use [Add Member](/docs/api/organizations/add-member); to email an invitation, use [Invite Member](/docs/api/organizations/invite-member).

**Permissions:** the `admin` role or above in the organization. API keys need the `org:write` scope. You can't assign a role above your own. The new member is checked against your own membership, so organization API keys are rejected with `401`.

### Path Parameters

<TypeTable
  type={{
    organizationId: {
      description: "Organization ID",
      type: "string",
      required: true,
    },
  }}
/>

### Request Body

<TypeTable
  type={{
    email: {
      description: "Email address for the new account (stored lowercased). Must not belong to an existing user",
      type: "string",
      required: true,
    },
    password: {
      description: "Password for the new account",
      type: "string",
      typeDescription: "At least 8 characters",
      required: true,
    },
    role: {
      description: "Role in the organization",
      type: "string",
      typeDescription: "\"owner\" | \"admin\" | \"editor\" | \"member\" | \"viewer\"",
      required: true,
    },
    name: {
      description: "Display name. Defaults to the email address",
      type: "string",
      required: false,
    },
  }}
/>

### Response

Returns `201`.

<TypeTable
  type={{
    message: {
      description: "Success message",
      type: "string",
    },
  }}
/>

### Error Responses

Errors use the standard body `{ error, code, message, resolution }`.

<TypeTable
  type={{
    "400": {
      description: "Missing email, password or role; invalid role; password under 8 characters; or a user with this email already exists",
      type: "object",
    },
    "401": {
      description: "No user behind the credential (organization API key)",
      type: "object",
    },
    "403": {
      description: "Not an admin or owner, a role above your own, or the organization is at its plan's member limit",
      type: "object",
    },
  }}
/>
