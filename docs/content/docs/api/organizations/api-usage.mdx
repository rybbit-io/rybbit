```
GET /api/organizations/:organizationId/api-usage
```

Returns how much of today's [daily API quota](/docs/api/getting-started#rate-limits-cloud-only) the organization's own API keys (`rb_org_`) have used. Personal keys are budgeted per user and aren't included.

**Permissions:** the `viewer` role or above in the organization. API keys need the `org:read` scope.

### Path Parameters

<TypeTable
  type={{
    organizationId: {
      description: "Organization ID",
      type: "string",
      required: true,
    },
  }}
/>

### Response

<TypeTable
  type={{
    metered: {
      description: "False on self-hosted instances, where API requests aren't metered (the daily figures are then 0)",
      type: "boolean",
    },
    available: {
      description: "False when the usage counter couldn't be read. The quota is still enforced; dailyUsed is then reported as 0 and dailyRemaining as the full dailyLimit, so the real remainder may be lower",
      type: "boolean",
    },
    dailyUsed: {
      description: "Requests made today",
      type: "number",
    },
    dailyLimit: {
      description: "The organization's daily quota",
      type: "number",
    },
    dailyRemaining: {
      description: "Requests left today",
      type: "number",
    },
    resetsInSeconds: {
      description: "Seconds until the quota resets at 00:00 UTC",
      type: "number",
    },
    burstLimit: {
      description: "Burst bucket size",
      type: "number",
    },
    burstWindowSeconds: {
      description: "Seconds for the burst bucket to refill completely",
      type: "number",
    },
  }}
/>
