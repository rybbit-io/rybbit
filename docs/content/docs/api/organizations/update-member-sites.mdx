```
PUT /api/organizations/:organizationId/members/:memberId/sites
```

Sets which sites a member can reach and the role they hold on them. This replaces the member's site grants: the `siteIds` you send become the full list.

- With `hasRestrictedSiteAccess: true`, the member reaches `siteIds` plus any sites granted to teams they belong to.
- With `hasRestrictedSiteAccess: false`, their per-site grants are removed and they reach every site that isn't limited to a team, plus the sites of their own teams. Sites limited to teams they aren't on stay hidden.

Team grants are managed separately, with [Teams](/docs/api/teams/update).

`siteRole` raises the member's role on the granted sites above their organization role (for example, an organization `viewer` who is an `editor` on one site). It never lowers it, and it stops at `editor`. Admins and owners always reach every site and can't be restricted.

**Permissions:** the `admin` role or above in the organization. API keys need the `org:write` scope.

### Path Parameters

<TypeTable
  type={{
    organizationId: {
      description: "Organization ID",
      type: "string",
      required: true,
    },
    memberId: {
      description: "Member record ID (the `id` returned by List Members, not the user ID)",
      type: "string",
      required: true,
    },
  }}
/>

### Request Body

<TypeTable
  type={{
    hasRestrictedSiteAccess: {
      description: "Whether the member is limited to siteIds",
      type: "boolean",
      required: true,
    },
    siteIds: {
      description: "Sites the member can reach. Every ID must belong to this organization",
      type: "number[]",
      required: true,
    },
    siteRole: {
      description: "Role on the granted sites. null grants no raise. Omit to keep the role existing grants carry (new sites get the role all existing grants share)",
      type: "string | null",
      typeDescription: "\"editor\" | \"member\" | \"viewer\" | null",
      required: false,
    },
  }}
/>

### Response

<TypeTable
  type={{
    memberId: {
      description: "Member record ID",
      type: "string",
    },
    hasRestrictedSiteAccess: {
      description: "The restriction now in effect",
      type: "boolean",
    },
    siteAccess: {
      description: "The member's site grants after the update",
      type: "{ siteId: number, role: string | null, name: string, domain: string }[]",
    },
  }}
/>

### Error Responses

Errors use the standard body `{ error, code, message, resolution }`.

<TypeTable
  type={{
    "400": {
      description: "Invalid siteRole, a site ID outside the organization, or an attempt to restrict an admin or owner",

    },
    "403": {
      description: "Not an admin or owner of the organization, or missing the org:write scope",
      type: "object",
    },
    "404": {
      description: "Member not found in this organization",
      type: "object",
    },
  }}
/>
