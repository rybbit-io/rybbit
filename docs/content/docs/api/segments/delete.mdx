```
DELETE /api/sites/:site/segments/:segmentId
```

Deletes a saved segment. Links that already expanded the segment's filters keep working.

Editors and above can delete any segment on the site, including through a per-site editor grant; members can delete segments they created. Organization-wide segments need the editor role or above in the organization, even for the segment's creator. Returns `403` when you may not delete it and `404` when it does not exist on this site.
