```
POST /api/sites/:site/segments
```

Creates a saved segment. Members create site segments they own; admins and owners can also create organization-wide segments.

### Path Parameters

<TypeTable
  type={{
    site: {
      description: 'Site ID or site identifier',
      type: 'string | number',
      required: true,
    },
  }}
/>

### Request Body

<TypeTable
  type={{
    name: {
      description: 'Segment name (1–80 characters)',
      type: 'string',
      required: true,
    },
    filters: {
      description: 'Filters that define the segment (1–20). Validated with the same schema as the `filters` parameter',
      type: 'Filter[]',
      typeDescription: 'See Filter Parameters in Getting Started',
      required: true,
    },
    description: {
      description: 'Optional notes (up to 500 characters)',
      type: 'string | null',
      required: false,
    },
    scope: {
      description: 'Where the segment is available. Organization-wide segments require an admin or owner',
      type: 'string',
      typeDescription: '"site" | "organization"',
      default: 'site',
      required: false,
    },
    isPublic: {
      description: 'Show on the public dashboard and private links',
      type: 'boolean',
      default: 'false',
      required: false,
    },
  }}
/>
### Response

Returns the created segment with status 201.

<TypeTable
  type={{
