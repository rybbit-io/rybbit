```
GET /api/sites/:site/gsc/status
```

Returns whether the site has a Google Search Console connection. Connect it in the dashboard under Site settings.

**Permissions:** any role on the site (`viewer` and above). API keys need the `gsc:read` scope. Public sites and [private links](/docs/api/sites/get-private-link) can read it without a key.

### Path Parameters

<TypeTable
  type={{
    site: {
      description: "Site ID or site identifier",
      type: "string | number",
      required: true,
    },
  }}
/>

### Response

<TypeTable
  type={{
    connected: {
      description: "Whether Search Console is connected",
      type: "boolean",
    },
    gscPropertyUrl: {
      description: "The connected Search Console property, or null when not connected",
      type: "string | null",
    },
  }}
/>
