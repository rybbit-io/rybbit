```
GET /api/sites/:site/gsc/data
```

Queries Google Search Console's Search Analytics for the site's connected property and returns its rows. The site must be [connected](/docs/api/search-console/status).

**Permissions:** any role on the site (`viewer` and above). API keys need the `gsc:read` scope. Public sites and [private links](/docs/api/sites/get-private-link) can read it without a key.

### Path Parameters

<TypeTable
  type={{
    site: {
      description: "Site ID or site identifier",
      type: "string | number",
      required: true,
    },
  }}
/>

### Query Parameters

<TypeTable
  type={{
    start_date: {
      description: "Start date",
      type: "string",
      typeDescription: "YYYY-MM-DD",
      required: true,
    },
    end_date: {
      description: "End date, on or after start_date",
      type: "string",
      typeDescription: "YYYY-MM-DD",
      required: true,
    },
    dimensions: {
      description: "Comma-separated dimensions to group by (1 to 3): query, page, country, device, date",
      type: "string",
      required: false,
    },
    dimension: {
      description: "Legacy single dimension (query, page, country or device). Rows then use a `name` key. Ignored when dimensions is set",
      type: "string",
      required: false,
    },
    filters: {
      description: "JSON-encoded array of up to 10 filters, ANDed: [{\"dimension\":\"country\",\"operator\":\"equals\",\"expression\":\"US\"}]. dimension is query, page, country or device; operator is equals (default), notEquals, contains, notContains, includingRegex or excludingRegex. With equals and notEquals, countries take ISO alpha-2 codes",
      type: "string",
      required: false,
    },
    search_type: {
      description: "Search Console search type",
      type: "string",
      typeDescription: "\"web\" | \"image\" | \"video\" | \"news\" | \"discover\" | \"googleNews\"",
      required: false,
    },
    data_state: {
      description: "`all` includes fresh, not yet final data",
      type: "string",
      typeDescription: "\"final\" | \"all\"",
      required: false,
    },
    row_limit: {
      description: "Maximum rows",
      type: "number",
      typeDescription: "1-25000",
      default: 1000,
      required: false,
    },
    start_row: {
      description: "Zero-based row offset, for paging",
      type: "number",
      required: false,
    },
  }}
/>

One of `dimensions` or `dimension` is required. This endpoint takes its own `filters` format, not the analytics filters.

<TypeTable

<TypeTable

Errors use the standard body `{ error, code, message, resolution }`.
